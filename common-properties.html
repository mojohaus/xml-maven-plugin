Common Goal Properties

All goals share the following properties:

Property Name Description
catalogHandling How to handle entities which cannot be resolved from the catalogs. There are 3 possible values:
- 'passThrough' indicates that the entity resolver should attempt to resolve system and public IDs through default mechanisms, typically by resolving URI formatted system IDs.
- 'local' indicates that the entity resolver should behave as for 'passThrough' but only where URI's are ‘file’ format URIs.
- 'strict' indicates that any entity which cannot be found in a catalog should generate an error.
catalogs A set of catalog files, which configure the entity resolver. For example, it allows to map public ID's or external URL's to local files. Multiple catalog files are supported. In other words, to configure a single catalog file, you would need a section like this:

  <catalogs>
    <catalog>mycatalog.xml</catalog>
  </catalogs>

You can use an optional ‘resource:’ prefix to load the catalog from the classpath. The interpretation of catalog files is done by the Apache XML resolver. See this article for details on catalog files and their formats.
jaxpConfigFile The path to a JAXP Config file (e.g. jaxp.properties). Note: This only has an affect in Java 21 and newer. See: https://docs.oracle.com/en/java/javase/21/docs/api/java.xml/module-summary.html#Conf_CF The JDK reads this file once per JVM, so the plugin applies the SchemaFactory and TransformerFactory classes it names itself; its other settings only take effect if nothing in the build has used JAXP before.
enableSchemaCaching Whether to keep the DTDs, schemas and other resources read from http, https and ftp URLs in memory, so each is downloaded once per execution and not once for every file that refers to it. Default is false. Property: xml.enableSchemaCaching.
skipIfMissingBaseDirectory Whether to skip a validation set or transformation set whose dir does not exist, with a message at info level, instead of failing the build. Default is false. Property: xml.skipIfMissingBaseDirectory.
